## 2. Тарифы

- Бесплатный тариф: все функции Сервиса, до 3 активных клиентов. Клиенты в архиве лимит не занимают.
- Подписка на месяц или на год: все функции Сервиса без ограничения числа активных клиентов.
- Будущие функции — расшифровка сессий, хранение записей, ИИ-помощник — показаны на экране тарифов с пометкой «Скоро». [Юристу: формулировка пометки «Скоро» без обязательства включить эти функции в текущую подписку (вопрос 6)]
- Смена тарифа не удаляет данные: клиенты, встречи, часы и суммы сохраняются.

- Год стоит как 8 месяцев.
- Скидки не складываются: действует самая низкая цена, на которую у аккаунта есть право.
- Цены пересматриваются раз в квартал. Пересмотр не меняет цену уже оплаченного периода.
- Подписка, оформленная в одном регионе, не распространяется на аккаунт того же человека в другом регионе. Партнёрские коды действуют в том регионе, в котором выпущены.

### 3.1. Промо-цена

- Промо-цена действует для оплаты в период акции, на оплаченный срок, в том числе при продлении действующей подписки.
- Следующее продление — по базовой цене, если в этот момент нет новой акции.

### 3.2. Партнёрская цена

- Партнёрская цена даётся по партнёрскому коду. Код активируется один раз на аккаунт, у кода есть срок активации и лимит использований; партнёр может ограничить код списком почт.
- Цена сохраняется, пока подписка продлевается без перерыва, в том числе при смене месяца на год и обратно.
- При переходе на бесплатный тариф партнёрская цена пропадает, повторно ввести код нельзя.
- Отключение кода не отменяет уже закреплённые цены.

## 4. Подписка, выданная администратором

- Администратор может выдать подписку до определённой даты. После этой даты действуют обычные правила.

## 5. Окончание подписки

- Если к окончанию подписки активных клиентов больше 3, Вы заранее выбираете трёх, которые останутся активными.
- Если выбор не сделан, остальные клиенты переходят в архив по правилу по умолчанию. Их запланированные встречи удаляются, клиенты получают уведомления об отмене. Прошлые часы и суммы сохраняются.

## 6. Оплата и возвраты

- Оплаты подписки в Сервисе пока нет: кнопка «Хочу подписку» сохраняет заявку, договор о платной подписке при этом не заключается.
