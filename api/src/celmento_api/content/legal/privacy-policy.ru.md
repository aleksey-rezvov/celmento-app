## 2. Чьи данные мы обрабатываем

- Люди, которые ведут клиентов в Сервисе.
- Люди с аккаунтом, которых ведут специалисты.
- Гости публичной страницы записи и люди, открывшие страницу встречи.
- Клиенты специалистов без аккаунта — их данные внёс специалист.
- Контактные лица партнёров.
- Выпускники и сотрудники партнёров, если партнёр передал список почт. [Юристу: основание для передачи партнёром списка почт выпускников и сотрудников (вопрос 15)]

### Данные о клиентах, которые вносит специалист

- Имя, фото, телефон, почта, Telegram, WhatsApp, другие контакты.
- Дата рождения, город, часовой пояс, важные даты.
- «С чем пришёл», «Текущие цели».
- «Информация о клиенте»: семья, профессия, близкие люди.
- «Гипотезы и наблюдения»: особенности, результаты тестов, типология.
- Встречи, их итоги, комментарии специалиста.
- Оплаты, баланс, ставка, валюта.
- Заметки с отметкой клиента, в том числе протоколы сессий.
- Источник: откуда пришёл клиент.
- Почта, которую клиент сам указал при записи на публичной странице, — отдельно от контактов, записанных специалистом.

Оператор данных своих клиентов — специалист. Мы обрабатываем их по поручению на обработку данных клиентов, которое специалист принимает при включении «Начать вести клиентов», и только для работы Сервиса. Специалист сам получает у клиентов согласие на обработку и отвечает за законность внесённых данных. Приватные поля карточки никогда не показываются клиенту, не попадают в выгрузки и недоступны администратору.

Контакты, которые специалист записывает в карточку, — справочные: мы не отправляем по ним писем, не проверяем их и не связываем по ним аккаунты. Карточка связывается с аккаунтом клиента автоматически — по почте, которую клиент сам указал при записи, — или по логину, который клиент сам сообщил специалисту. Клиент получает уведомление о связи и может её разорвать.

## 5. Кому мы передаём данные

- Специалисту — данные гостя и клиента, записавшегося к нему.
- Специалисту, пригласившему человека на встречу, — имя и логин нового аккаунта, если при регистрации со страницы встречи осталась отмеченной галочка «Сообщить» этому специалисту.
- Клиенту — данные из связанной карточки в объёме, описанном в пользовательском соглашении: встречи с этим специалистом и заметки с его отметкой.
- Подрядчикам: хостинг, сервис отправки писем, в будущем — платёжный провайдер. [Заполнить после выбора команды: подрядчики — хостинг, сервис отправки писем, платёжный провайдер]
- ИИ-ассистенту администратора — только публичные профили, обратную связь и обезличенную статистику. [Заполнить: ИИ-провайдер администратора] [Юристу: трансграничная передача данных ИИ-провайдеру и другим подрядчикам (вопрос 17)]
- Партнёру — только обезличенное число активаций его кода. [Юристу: подтвердить, что партнёр получает только обезличенное число активаций]
- В Telegram, WhatsApp, Google Meet и другие приложения данные не передаются: Сервис только открывает эти приложения на устройстве.
- По Вашему действию данные могут уходить за пределы Сервиса: «Отправить текстом» в мессенджер, «Добавить в календарь», выгрузка табеля. Выгрузка табеля содержит имена и контакты клиентов, Сервис предупреждает об этом перед выгрузкой. Передача такого файла третьим лицам, например в ICF, — ответственность специалиста.

## 6. Где хранятся данные

- Сервис работает в двух независимых регионах: «Россия» (celmento.ru) и «Остальной мир» (celmento.com). Общей базы аккаунтов и общего справочника почт у регионов нет, данными они не обмениваются.
- Регион выбирает сам пользователь при завершении регистрации; пришедшему по ссылке специалиста или встречи достаётся регион специалиста. Страна подключения и IP-адрес в этом выборе не участвуют. Изменить регион позже нельзя.

## 7. Как долго мы храним данные

- Незавершённая регистрация хранится только на устройстве человека 24 часа; до нажатия «Завершить регистрацию» мы не создаём записей о нём.

## 9. Как устроена приватность

- Любую заметку и любое поле видит только автор. Другой человек получает доступ к заметке только через явную отметку в ней; снятие отметки закрывает доступ сразу.
- Приватные поля карточки клиента — «С чем пришёл», «Текущие цели», «Информация о клиенте», «Гипотезы и наблюдения» — клиент не видит ни при каких условиях.
- Специалисты одного клиента не видят друг друга и данные друг друга.
- Администратор не видит заметки, карточки клиентов, встречи и балансы конкретных людей. Ему доступны публичные профили, обратная связь, обезличенная статистика и технические сведения об аккаунте. Все действия администратора записываются в журнал.
- Почта автора обратной связи показывается администратору только по отдельной просьбе.
- Мы планируем: блокировку приложения PIN-кодом или биометрией; настройку «Скрывать подробности в уведомлениях»; подтверждение связи карточки клиентом; подсказку под приватными полями карточки «Записывайте только то, на что клиент дал согласие» и подсказку не писать имена клиентов в «Что улучшить?»; удаление отдельной карточки клиента.

## 10. О чём стоит сказать отдельно

- Автоматических решений, которые влияют на Вас, нет. Исключение — автоматическая архивация клиентов при окончании подписки по правилу, которое специалист может заранее изменить.
- Геолокация не используется. Для показа времени берётся часовой пояс устройства.
- ИИ-функции для пользователей, например расшифровка сессий, появятся позже. Перед их запуском мы обновим политику. Сейчас ИИ-ассистент есть только у администратора, см. раздел 5.
- В приложении cookie не используются или используются только технически необходимые. [Заполнить: какие cookie используются на публичной странице записи — подтверждает команда]
